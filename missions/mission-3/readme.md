# 🚀 Mission 03 - Give Your AI a Personality

## 🎯 Mission Objective

Learn how to customize the behavior of an AI assistant using a System Instruction.

---

## 📚 What I Learned

### What is a System Instruction?

A System Instruction tells the AI how it should behave before the user starts chatting.

Examples:

- Teacher
- Software Engineer
- Interviewer
- Travel Planner

The AI model remains the same.

Only its behavior changes.

---

## Difference

System Instruction

↓

Defines AI personality.

User Prompt

↓

Actual question asked by the user.
